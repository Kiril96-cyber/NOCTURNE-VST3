# NOCTURNE + FL Studio (Windows)

## Сборка
1. Установите Visual Studio 2022 (Desktop development with C++) и CMake 3.22+.
2. Запустите `build_windows.bat` из папки проекта. При первой сборке CMake скачает JUCE 8.0.6, поэтому нужен интернет.
3. После успешной сборки найдите `NOCTURNE.vst3` в `build/NOCTURNE_artefacts/Release/VST3/`.
4. Скопируйте bundle в папку VST3, которую сканирует FL Studio, либо добавьте папку в Plugin search paths и выполните Verify plugins.

## Запись вокала в реальном времени
1. В FL Studio выберите аудиовход микрофона в Mixer Insert.
2. Добавьте NOCTURNE на этот Insert и включите мониторинг входа.
3. Для одновременного прослушивания голоса направьте Insert на Master.
4. Нажмите RECORD в NOCTURNE и пойте. Ноты будут отображаться в интерфейсе; при включённом RECORD плагин также выдаёт MIDI note-on/note-off события.
5. MIDI-выход VST3 зависит от поддержки и настройки маршрутизации в конкретной версии FL Studio. Если MIDI-выход не появляется как источник для другого канала, используйте EXPORT MIDI: это надёжный перенос партии в Piano Roll.

## Импорт готового аудио
Нажмите IMPORT AUDIO и выберите WAV, AIFF, FLAC или MP3. Алгоритм рассчитан на одну доминирующую мелодическую линию (например, чистый вокал без аккомпанемента). Затем используйте EXPORT MIDI.

## Примечания к текущему прототипу
- Детектор YIN-подобный, монофонический; он не разделяет аккорды и смешанные инструменты.
- READ SPEED задаёт внутренний параметр частоты обработки; это не изменение BPM проекта.
- NOTE ACCURACY — порог доверия распознаванию.
- PITCH GLIDE сглаживает скачки высоты тона; слишком высокое значение может сгладить быстрые мелизмы.
- MIDI экспортируется отдельным `.mid` файлом; экспорт напрямую в Piano Roll требует host-specific workflow.
- Это исходный код прототипа, не подписанный и не собранный Windows-бинарник. Перед релизом необходимы компиляция и тестирование в вашей версии FL Studio.

## Новое в v0.3
- После импорта файла отображается форма волны.
- Ноты показаны в piano roll. Перетаскивайте ноту вверх/вниз для смены высоты и влево/вправо для изменения начала.
- BPM и MIDI Quantize применяются при экспорте MIDI (OFF, 1/4, 1/8, 1/16, 1/32).
- Длина ноты пока не редактируется перетаскиванием; нет выделения нескольких нот, Undo и синхронизации BPM с темпом проекта FL Studio.
- Добавлен параметр Vibrato Tolerance: он усиливает стабилизацию высоты тона и помогает избежать частых скачков между соседними полутонами при вибрато.
