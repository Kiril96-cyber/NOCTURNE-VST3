# NOCTURNE + FL Studio (Windows)

## Установка
1. Установите Visual Studio 2022 (Desktop development with C++) и CMake 3.22+.
2. Запустите `build_windows.bat` из папки проекта. При первой сборке CMake скачает JUCE 8.0.6, поэтому нужен интернет.
3. После успешной сборки найдите `NOCTURNE.vst3` в `build/NOCTURNE_artefacts/Release/VST3/`.
4. Скопируйте bundle в VST3-папку, которую сканирует FL Studio, либо добавьте папку в Plugin search paths и выполните Verify plugins.

## Подключение аудио и запись вокала
NOCTURNE анализирует аудио, поступающее на его вход. Это важно: само нажатие RECORD не включает микрофон и не выбирает вход FL Studio.

1. Откройте Mixer и выберите Insert для микрофона или вокальной дорожки.
2. В меню Input этого Insert выберите физический вход аудиоинтерфейса, куда подключён микрофон.
3. Добавьте NOCTURNE в слот эффектов этого Insert.
4. Включите мониторинг входа и проверьте, что на Mixer Insert двигается индикатор уровня.
5. Откройте NOCTURNE. При поступлении звука должна двигаться область LIVE INPUT WAVEFORM, а LIVE PITCH должен показывать частоту и ноту.
6. Нажмите RECORD внутри NOCTURNE, исполните партию и нажмите STOP.
7. Проверьте ноты в Piano Roll плагина. Для переноса в проект нажмите EXPORT MIDI, затем импортируйте полученный .mid через File > Import > MIDI file.

Если LIVE INPUT WAVEFORM остаётся плоской и INPUT равен нулю, FL Studio не подаёт аудио на вход NOCTURNE. Сначала исправьте маршрутизацию Mixer Insert, а не настройки Pitch.

## Импорт готового аудио
Нажмите IMPORT AUDIO и выберите WAV, AIFF, FLAC или MP3. В текущем прототипе детектор ищет одну доминирующую линию высоты тона; лучше всего работает чистый вокал без громкого аккомпанемента. После анализа ноты появляются в Piano Roll, затем используйте EXPORT MIDI.

## Pitch и очистка нот
- READ SPEED задаёт частоту обновления анализа, а не BPM проекта.
- NOTE ACCURACY задаёт минимальную уверенность детектора. Если ноты пропадают, немного уменьшите порог; если появляются ложные ноты, увеличьте.
- PITCH GLIDE сглаживает быстрые колебания высоты.
- VIBRATO TOLERANCE удерживает ноту при небольшом вибрато и коротких провалах сигнала.
- TRANSITION STABILITY задаёт, насколько долго новый тон должен подтверждаться, прежде чем текущая нота сменится. Увеличьте значение, если на переходах появляются лишние короткие ноты; уменьшите для быстрых мелодических пассажей.
- CHORD MODE может расширить распознанную основную ноту до MAJOR, MINOR, DIMINISHED, AUGMENTED, SUS2 или SUS4. Все ноты выбранного аккорда запускаются одновременно.

## Что пока не реализовано
- CHORD MODE строит выбранное созвучие от распознанной основной ноты. Это не полноценное разделение произвольного многоголосного аудиофайла на все одновременно звучащие исходные ноты.
- Основной Pitch detector остаётся монофоническим и ориентирован на один ведущий вокальный/инструментальный источник.
- MIDI-выход VST3 зависит от поддержки и маршрутизации конкретной версии FL Studio. Если MIDI-выход NOCTURNE не появляется как источник для другого канала, используйте EXPORT MIDI — это надёжный путь переноса партии.
- Piano Roll показывает и редактирует ноты внутри плагина. Перенос партии в Piano Roll FL Studio выполняется через экспорт MIDI.
- Перед релизом необходимы компиляция и тестирование собранного VST3 в вашей версии FL Studio.

## Piano Roll
Во время записи длина активной ноты обновляется в реальном времени, отображается позиция записи и живая форма входного сигнала. Диапазон нот автоматически подстраивается под текущий вокальный регистр. Ноты можно перемещать по высоте и времени.
